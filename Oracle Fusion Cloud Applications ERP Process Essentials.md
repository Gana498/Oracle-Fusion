## Redwood Design & AI in Oracle Fusion Cloud Applications

### Redwood Design System

- **Next-generation user experience** from Oracle.
- Includes prefabricated components, templates, and patterns.
- Enables developers to build sophisticated, polished, upgrade-safe interactions.
- Offers a **consumer-grade-plus experience**:
  - High-quality functionality across devices.
  - Quick access to insightful data.
  - Personalization options for a tailored experience.
- Improves productivity with:
  - Fewer clicks
  - Faster downloads
  - Streamlined processes

### Intelligent & Adaptable UX

- **AI-powered recommendations and guidance** based on user preferences and business processes.
- **Adaptability**:
  - Use same tools to create new experiences.
  - Leverage business rule framework with modern UX components.

### Oracle Visual Builder Studio

- Robust platform for building and extending web, mobile, and progressive web apps.
- Features:
  - Visual development environment
  - Reduced coding
  - Support for popular build/testing frameworks
  - REST service integration
  - Code lifecycle and development process management
  - Hosting, publishing, and version control

### Application Extensions via Visual Builder Studio

- Modify UI by displaying fields from data sources.
- Add business logic and edit variables, constants, and events.
- Use **Business Rules** (Redwood equivalent of Transaction Design Studio):
  - Customize pages based on criteria (e.g., country, business unit).
  - Control field visibility, editability, and requirement status.
- Use **Constants** to:
  - Hide panels
  - Reorder columns
  - Customize Redwood pages for specific business needs

- Combines **classic and generative AI**.
- Seamless integration into daily workflows.

#### CX (Customer Experience)
- Identifies high-potential sales leads.
- Sends real-time news alerts.
- Recommends actions to improve conversion rates.

## AI Agents in Fusion Applications

### What Are AI Agents?

- Combine **large language models (LLMs)** with advanced tech.
- Automate complex tasks and collaborate with humans.
- Capable of reasoning and judgment.
- Learn from interactions and adapt continuously.

### Types of AI Agents

- **Functional Agents**: Perform domain-specific tasks for enterprise personas.
- **Supervisory Agents**: Manage other agents and workflows.
- **Utility Agents**: Handle routine tasks like data retrieval and notifications.

### Real-World Use Cases

- **HR**: Assist with benefits and policy inquiries.
- **Finance**: Automate invoice approvals and optimize workflows.
- **SCM**: Guide technicians with diagnostics and automate parts ordering.
- **CX**: Automate contract workflows for sales teams.

### Strategic Impact

- AI agents go beyond automation to **collaborate** with users.
- Improve productivity and operational efficiency.
- Future potential: Manage entire business processes autonomously.
